# Stock Prediction Analysis with LSTM Architecture

This project focuses on stock price prediction using a Long Short-Term Memory (LSTM) model on Amazon and Cisco stock data. Through pre-processing, time series analysis, and model evaluation, it aims to provide insights into forecasting stock prices with deep learning.

## Project Overview
The project demonstrates:
- **Data Pre-processing**: Time series data preparation and data splitting using a windowing method.
- **LSTM Model Implementation**: Developing an LSTM model as the baseline architecture for stock price prediction.
- **Evaluation and Visualization**: Using multiple metrics to evaluate performance (MAE, MAPE, MSE, RMSE) and plotting comparisons between actual and predicted values.

### Key Achievements:
- Successfully prepared Amazon and Cisco stock data for time series analysis.
- Built and evaluated an LSTM model using various evaluation metrics to assess prediction accuracy.
- Created visual plots to compare the original stock prices with model predictions, aiding in performance assessment.
